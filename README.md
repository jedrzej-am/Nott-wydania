# Nott — wydania

Binarki wydań aplikacji Nott (macOS). Kod źródłowy jest w prywatnym repo.

Instalacja: pobierz DMG z najnowszego wydania, przeciągnij Nott do Aplikacji.
Przy pierwszym uruchomieniu macOS poprosi o zgodę: Ustawienia → Prywatność i ochrona → „Otwórz mimo to”.
Aktualizacje aplikacja pobiera i instaluje sama.
