# Nott — wydania

Binarki wydań aplikacji Nott (macOS, Apple Silicon). Kod źródłowy jest w prywatnym repo.
Strona: https://jedrzej-am.github.io/Nott-wydania/

## Instalacja jedną komendą (polecane)

```bash
curl -fsSL https://raw.githubusercontent.com/jedrzej-am/Nott-wydania/main/instaluj.sh | bash
```

Komenda pobiera najnowsze wydanie, instaluje do /Applications i uruchamia aplikację.
Kolejne aktualizacje Nott pobiera i instaluje już sam.

## Instalacja ręczna (DMG)

Pobierz DMG z najnowszego wydania, przeciągnij Nott do Aplikacji.
Przy pierwszym uruchomieniu macOS poprosi o zgodę: Ustawienia → Prywatność
i ochrona → „Otwórz mimo to" (podpis jest ad-hoc — bez konta deweloperskiego).
Aktualizacje aplikacja pobiera i instaluje sama.
